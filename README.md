# knowledge-learning-skill# 知识学习 Skill

面向初学者的中文学习技能，帮助理解概念、项目整体逻辑，
以及真实代码的含义和目的。

特点：
- 用连贯、易懂的中文解释陌生概念
- 只在影响讲解方向时适量追问
- 主动画出复杂的调用、数据流和依赖关系
- 沿着真实功能阅读代码，解释代码为什么存在

## 安装到 Codex

在 Codex 中输入：

请使用 skill-installer，从这个 GitHub 地址安装知识学习 Skill：
https://github.com/B1UERY/knowledge-learning-skill
## 使用示例

- 用知识学习，带我看懂这个项目的整体逻辑。
- 用知识学习，解释这个函数的执行过程，复杂关系请配图。
